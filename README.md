## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- Python (v3.8+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Davoadeivai/sazeyar1.git

# Navigate to project directory
cd sazeyar1

# Install dependencies
npm install
# or
pip install -r requirements.txt
```

### Running the Project

```bash
# Development mode
npm run dev

# Build for production
npm run build

# Run tests
npm test
```
